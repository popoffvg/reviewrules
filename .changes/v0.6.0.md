## v0.6.0 - 2026-11-27
### Added
* A run keeps the verdict of a correctness question while the files the verdict cites and the --context notes stay the same, so a verdict no longer flips between runs; the summary marks it `reused from <commit>` and the JSON report sets `reused_from`. A new note checks CONFIRMED and UNSURE verdicts again, and a --worktree run checks every question.
### Changed
* A `light` rule now judges each hunk that adds a line, in small batches per fork, and lists every hit, not the first one; a rerun on the same branch reuses the verdict of each unchanged hunk and asks only about the hunks that changed. A `prompts_dir` can replace the new `rule_hunk_check.md.tmpl`.
### Fixed
* A run while a tracked file has an uncommitted edit no longer stores a correctness or `light` rule verdict, because its checks can read that edit; such a run checks every question again and leaves the cache as it was. A `--worktree` run stores no `light` rule verdict either.
