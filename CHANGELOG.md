## v0.1.0 - 2026-11-20
### Added
* A rule's `profile` field (light, medium, or heavy) picks the model, effort, and steps of its check from the `[<case>.profiles.<name>]` table of the user config
* `[<case>.rule_dirs]` in the user config adds local rule folders, such as the notes folder of a repo, with no fetch
* With no `agent` in the user config, reviewrules uses the one backend it finds on the machine (claude or codex in PATH, or LITELLM_API_KEY, OPENAI_API_KEY, or OPENROUTER_API_KEY set), and stops with the config line to write when it finds none or several
### Changed
* An unset `model` or `hypothesis_model` takes the default of the agent: claude now runs sonnet and codex its own default model, not gpt-6-luna
* An UNSURE correctness hypothesis gets a second check that reads its callers up to the entry point; a hypothesis that stays UNSURE now gives exit code 1
